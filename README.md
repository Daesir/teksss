# Sidang Nalar

Game sidang bergaya Ace Attorney jadul untuk belajar teks diskusi kelas VIII.

Satu file `index.html` berisi seluruh tampilan, logika, dan font piksel.
Workflow `.github/workflows/build-apk.yml` membungkusnya menjadi APK dengan Capacitor.
APK muncul di tab Actions, pada bagian Artifacts di halaman run.
